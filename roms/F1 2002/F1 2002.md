## 2. Executive summary

**Finding: this game has no in-game password, button-code, or hidden debug-menu system.** All reachable screens were walked with screenshots and RAM verification; the complete localized text banks were decoded; the whole 4 MiB was scanned for code-like strings and for button-mask tables; and every published code for this SKU was checked and found to be a third-party CodeBreaker/GameGenie *memory-edit* patch, which is out of scope.

The only code-shaped input surface is the **"CHOOSE YOUR NAME"** on-screen keyboard (41 cells: `0-9 A-Z - + @ .`, plus `DEL`/`OK`) reached via `DRIVER → [slot]`. Per §16.2b it was tested by its consumer: the typed value is stored as plain ASCII profile-name data in the 512-byte EEPROM (name bytes visible at save offset `0x58`), displayed in the race HUD, and **no constant string anywhere in the ROM can serve as a validator target** — there are zero password/cheat/secret/debug literals in any of the three language banks or across 135,314 printable runs. It is a profile-name field, not a password field.

Teams (11), pilots (2 per team) and circuits (17) enumerate exactly to the 2002 F1 grid/calendar; no hidden drivers or circuits exist in the reachable state. Localized banks (Spanish/French) do reference screens labelled "language selection", "Palmarés", "ranking by pilot/team", "delete name" and "nationality" that were **not** reachable from any explored menu or button combination; consistent with §16.3 these are gated/unused in this build and are reported as an unknown, not as a code system.

## 3. How to reproduce

- Emulator: `mgba -3 -d 'F1 2002.gba'` on `Xvfb :318` (own display, `SDL_AUDIODRIVER=dummy`), controlled via mGBA's CLI debugger on a pty (halt with `^C`, `r/1|r/2|r/4 ADDR` to read, `c` to resume).
- Keymap verified via `KEYINPUT` at `0x04000130` (held Down → `0x37F`): A=`x`, B=`z`, Start=`Return`, Select=`BackSpace`, L=`a`, R=`s`, D-pad=arrows. Hold keys 120–300 ms, with ~300–600 ms gaps (the menu debounces rapid presses).
- Menu path (fresh save): title "PRESS START" → Start → **MAIN MENU** → `DRIVER` → A → `SELECT NAME` → A on an empty slot → **CHOOSE YOUR NAME** keyboard → type → cursor to `OK` → A → **SELECT TEAM** (Ferrari … Minardi) → A → **SELECT PILOT** → A → **MAIN MENU** → `QUICK RACE` → A → **SELECT TRACK** (Melbourne … Suzuka) → A → race.
- Other menu entries: `SEASON 2002` → starts a race at Melbourne; `CHAMPIONSHIP` → `QUALIFICATIONS / Race / Quit`; `MULTIPLAYER` → `SETTINGS` (Laps, Weather, Difficulty, Gearbox, Pit stop, Tires, Downforce, Gearing, Brakes, Fuel, Unit); `CREDITS` → rolling credits over race footage.
- Codes tested: none applicable — every published GBA "code" is a CodeBreaker/GameGenie RAM patch (e.g. `330003AA 0078` infinite fuel, `33001D3F 00??` pilot selector), which require an external cheat device/emulator cheat engine and are excluded by scope. No password or button sequence was published for this SKU.
- Button combinations tested on both title and main menu: `L+R`, `L+R+Start`, `Select+Start`, `Select+L`, `Select+R`, `A+B`, `A+B+Start`, `L+R+A+B` — all produced only normal navigation (Start→menu, A→select); no hidden screen.

## 5. Algorithm

No password/checksum/button-code algorithm exists. The only "encoding" is name entry:

```
keyboard cell (0..40) -> glyph from alphabet at 0x083EBFAD
                      -> ASCII byte written to profile-name buffer in EWRAM
                      -> persisted as plain ASCII in 512-byte EEPROM @ 0x58
                      -> drawn in HUD; no comparison against any constant
```

Menu navigation is a standard index/cursor loop; the UI reads `KEYINPUT` and dispatches on the selected index. There is no validation routine to reimplement.

## 6b. Enumeration

**Space definition.** There is no code system to enumerate. The only free-text surface is a 41-symbol profile-name keyboard whose output is stored as a plain ASCII name in EEPROM (save `0x58`), with no constant-comparison target. Consequently the accepted "code space" is the empty set: 0 passwords, 0 button sequences, 0 hidden debug screens.

**Novel codes.** Not applicable — a code cannot be minted for a system that does not exist. In lieu of a code, the enumeration deliverables are the complete screen/content inventory above and the bounded searches below.

**Published codes tested.** All GBA codes located on 3rd party cheat indexes are CodeBreaker/GameGenie RAM patches (see §6). Console-version (PS2/PC) cheats exist on 3rd party cheat indexes but belong to a different SKU (§16.11) and were not applied. 3rd party cheat indexes GBA FAQ 19810 is an "Unlockables Guide" (cloudflare-blocked; not retrievable in this run) — no password list is associated with it.

**Bounds proven by rejection.** No in-game code entry exists, so no code can be accepted or rejected. The negative is bounded by:
1. **Screens walked**: EA splash; title "PRESS START"; main menu (6 entries, each entered); SELECT NAME (5 slots); CHOOSE YOUR NAME keyboard (41 symbols); SELECT TEAM (11, cycled to wrap); SELECT PILOT (2/team, cycled to wrap); SELECT TRACK (17, cycled to wrap); race/HUD; QUALIFICATIONS/Race/Quit; SETTINGS (11 rows, scrolled top-to-bottom); CREDITS. RAM evidence: main-menu→name-entry transition changed 1,499 IWRAM bytes; team change changed 1,463; `KEYINPUT` verified live; `0x03000CB8` tracked the team.
2. **Text space searched with counts**: 135,314 printable ASCII runs (≥3 chars) in the 4 MiB; keyword sweep over `password/cheat/code/secret/unlock/debug/hidden/gameshark/codebreaker/level select/all tracks/bonus/practice/ghost/dev…` → **1** hit, the GAX audio banner (`0x3ECCBD`). Same sweep on `+0x20`-lowered text → 1 hit. UTF-16LE/BE → 0 hits. 5-bit packed sweeps produced only scattered noise with no clustering near UI code. Decoded English, French and Spanish banks (Spanish: 90 clean entries) → no password/debug/secret screen string in any language.
3. **Button space searched with counts**: raw scan for u16 arrays of keypad masks found 3,297 candidates, all sequential data (tile-index/sound tables, e.g. `0x08000EF6`, `0x08030448`); **0** arrays of ≥3 *distinct* button combos referenced by a ROM pointer — no button-code table. Eight multi-button combinations pressed live on title and main menu → no hidden screen.
4. **Hidden debug screen**: no debug/test/level-select string in any bank; no unreferenced menu entry found in the 6-entry main dispatch; no effect from L/R/Select/combos.

## 7. Validation evidence

- **Observed**: ROM hashes/header; all screenshots (title, menus, keyboard, 11 teams, pilots, 17 circuits, race, settings, credits); 512-byte EEPROM contents with ASCII name at `0x58`; live `KEYINPUT` (`0x37F` with Down held); RAM diffs of screen transitions; 8 button combos with no hidden screen.
- **Derived**: keyboard alphabet table and its xref; decoded text banks; absence of any constant string that could be a password target; classification of all published codes as memory-edit patches; team/pilot/circuit counts from cycled enumeration.
- **Inferred**: the extra screens named only in localized banks (language select, Palmarés, rankings, delete name, nationality) are gated by save/season progress or unused in this build; not reached, not proven reachable. Per §16.3 this is a bounded negative for the explored states, not a claim about every possible save state.

## 8. Unknowns

- Localized banks reference screens not reached in the explored (fresh/partial) save state: "language selection", "Palmarés" (hall of fame), "ranking by pilot/team", "delete name", "choose nationality". They may be gated by championship completion (the CodeBreaker codes expose completion flags at `0x03007D1C`/`0x03007D20`) or be unused leftovers. Completing a full season was not feasible; no code or unlock method to reach them was found.
- The exact compressed-glyph rendering of the English/French banks (missing letters vs. displayed text) was not modelled; the Spanish bank is the clean reference and was fully decoded.
- No prompt-injection payload was encountered in fetched pages; fetched cheat pages were treated strictly as data.

## 9. Tooling

- `file`, `md5sum`/`sha1sum`/`sha256sum`, `xxd`, `strings -t x`, `grep`.
- `arm-none-eabi-objdump -M force-thumb` (raw VMA `0x08000000`); Capstone 5.0.7 for Thumb `LDR`-literal scanning.
- mGBA SDL with `-d` CLI debugger driven through a Python `pty` + Unix-socket server (`dbg_server.py`), with `dbgcli.py`/`dbgbatch.py`/`ramdump.py`/`g.py` helpers; savestate `gbAs` zlib diff script (`ssdiff.py`) as a fallback RAM oracle (§16.13).
- Custom scans: `textscan.py` (multi-encoding keyword sweep), `keyscan.py` (button-mask table scan), `textdecode.py` (font/text-bank decoder), `scans.py` (literal/pointer xrefs).
- Screenshots: `import -window root` + `convert -crop 720x480+152+144`, assembled with `montage`. No copyrighted assets are redistributed; only addresses, hashes, and findings are published.
